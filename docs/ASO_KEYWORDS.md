# ASO keywords — Pdf Reader

Launcher name (on the phone): **Pdf Reader** (set in `app.config.ts`).
Play Store title, short description and long description are separate from the launcher name and are written in T7.1 from the lists below.

Google Play has no hidden keyword field. Ranking comes from the title, the short description and the long description, so the keywords have to appear there in natural sentences. Before T7.1 is published, re-check the current Google Play metadata policy (needs human verification): no keyword stuffing or repeated keyword lists, no "best" / "#1" / "free" / price claims in the title, and no claims about features the app does not have.

## Keyword list

| Keyword | Where to use | Available at launch? |
|---|---|---|
| pdf reader | title (lead word), short desc, long desc | yes |
| pdf viewer | title, long desc | yes |
| pdf reader offline / offline pdf reader | title or short desc, long desc | yes |
| pdf reader for android | long desc | yes |
| pdf scanner / document scanner | title or short desc, long desc | yes |
| compress pdf / reduce pdf size / pdf to 100kb | long desc, screenshot captions | yes |
| image to pdf / photo to pdf | long desc | yes |
| merge pdf / split pdf | long desc | check against shipped tasks |
| sign pdf | long desc | check against shipped tasks |
| pdf editor | long desc only, worded honestly | partial at launch; keep it modest |
| document reader | long desc | **only after T2.10 (Office viewing) ships** |
| all document viewer / all document reader | long desc | **only after T2.10 ships** (DOCX, XLSX, CSV, TXT) |
| word viewer, excel viewer, docx reader | long desc | **only after T2.10 ships** |
| whatsapp documents | long desc | yes |

Rule: a keyword that describes a feature goes into the listing only when that feature is in the released build. "All document viewer" before Office viewing ships would be a misleading claim.

## Title options (Play limit: 30 characters)

1. `PDF Reader: PDF Viewer Offline` (30)
2. `PDF Reader & Scanner - Offline` (30)
3. `Pdf Reader - PDF Viewer & Scan` (30)

Recommendation: option 1 at launch, since it covers the three highest-intent searches (pdf reader, pdf viewer, offline). Use the short description to add the scanner and compression.

## Short description draft (Play limit: 80 characters)

`Fast offline PDF reader & viewer. Scan, compress, sign PDFs. No ads in reader.` (78)

Drop "sign" if signing is not in the launch build.

## Long description

Write it in T7.1. Use each primary keyword 2–3 times in normal sentences, plus feature bullets and the privacy and "no ads while reading" promise. Once T2.10 ships, add a section on opening Word, Excel and text files ("document reader", "all document viewer").
